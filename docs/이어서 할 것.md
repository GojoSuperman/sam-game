## 아직 git 이 아닙니다

이 프로젝트는 git 저장소가 아니라 **이 노트북에만 있습니다.**
데스크탑에서 이어가려면 git init + GitHub 푸시가 필요합니다.
`.gitignore` 는 이미 `.env`·`.env.local` 을 막도록 되어 있고 `git check-ignore` 로 실증했습니다.
`.env`/`.env.local` 의 SAM 키 4개는 git 에 안 들어가므로 별도 이전이 필요합니다
(`/mnt/f/Project-App/scripts/sync-secrets.sh`).
